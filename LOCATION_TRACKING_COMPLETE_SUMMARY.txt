================================================================================
  COMPLETE DATA FLOW (NOW WORKING)
================================================================================

DRIVER SIDE:
  1. Driver clicks "Start Trip"
  2. DriverLocationTracking component:
     - Joins booking room: socket.emit('join_booking_room', bookingId)
     - Joins driver room: socket.emit('join-driver-room', driverId)
     - Starts GPS tracking (every 10 seconds)
  3. Every 10 seconds:
     - POST /driver/update-location (REST API for persistence)
     - socket.emit('driver-location-update', {driverId, location, bookingId, tripId})

BACKEND:
  1. Receives driver-location-update event
  2. Broadcasts to specific rooms:
     - io.to(`booking-${bookingId}`).emit('driver-location-update', {...})
     - io.to(`trip-${tripId}`).emit('driver-location-update', {...})
  3. Sends confirmation to driver:
     - io.to(`driver-${driverId}`).emit('location-confirmed', {...})

PASSENGER SIDE:
  1. Passenger opens booking page
  2. LiveTracking component:
     - Joins booking room: socket.emit('join_booking_room', bookingId)
  3. Listens to real-time updates:
     - socket.on('driver-location-update', (data) => setLiveDriverLocation(...))
  4. Map updates in real-time:
     - Driver marker moves
     - Route recalculates
     - ETA updates

RESULT: Real-time location tracking visible on passenger's map! 🎉
